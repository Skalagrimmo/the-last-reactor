# Asset provenance

Everything in this repository is original and generated by the repository's
own code at runtime. There are **no image, font, audio or data files** in
this project — the PNGs in `docs/screenshots/` are documentation captures
produced by `tests/capture-harness.js`, not game assets.

- **Tiles and sprites** — drawn by `js/assets.js` as code: an 8×8 pixel map
  per sprite, painted through `fillRect` on a 256×240 canvas. Palette
  definitions live in the same file.
- **Typography** — a 3×5 bitmap font (`js/core.js`), including glyphs for
  `0-9`, `A-Z`, punctuation and an em-dash; rendered pixel by pixel.
- **Sound** — `js/audio.js` generates square-wave beeps with WebAudio
  oscillators. No audio files exist or are needed.
- **World** — carved procedurally by `js/world.js` from fixed district
  anchors; enemy packs and contents seeded through the game's LCG.
- **Screenshots** — `docs/screenshots/*.png` are encoded by the harness's
  own PNG encoder (indexed colour, stored deflate) from the game's own
  renderer, at a fixed frame from a fixed seed.

No third-party assets, libraries, fonts, or audio are used or required.
